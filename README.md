# RAG-KnowledgeBase

## 1. 项目简介
基于 HowToCook 的中文菜谱 RAG 问答系统。

## 2. 核心功能
- 中文自然语言菜谱问答
- 自动 Query Decomposition
- 多菜谱对比查询
- Dynamic Evidence Selection
- 基于证据的答案生成与引用

## 3. 技术架构
- Python 3.12 / uv
- FastAPI
- BAAI/bge-small-zh-v1.5
- ChromaDB
- OpenAI 兼容的 LLM API
